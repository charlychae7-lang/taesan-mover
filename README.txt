태산 이사 도우미 (태산익스프레스 고객 서비스)

[쓰는 법]
1. 이 압축 파일을 풀어요. (파일을 오른쪽 클릭 -> 압축 풀기)
2. 풀린 폴더에서 index.html 을 두 번 눌러요. 인터넷 창에서 앱이 열려요.
3. 사용법은 manual.html 을 열어 보세요. 그림과 유저 스토리가 들어 있어요.

[알아 두세요]
- 회원가입, 로그인, 설치가 필요 없어요. 무료예요.
- 입력한 내용은 쓰고 있는 기기의 인터넷 창 안에만 저장돼요. 밖으로 나가지 않아요.
- 다른 기기에서 열면 처음부터 다시 입력해야 해요.
- 행정 절차의 기한과 방법은 바뀔 수 있어요. 중요한 일은 정부24나 주민센터에서 확인하세요.
